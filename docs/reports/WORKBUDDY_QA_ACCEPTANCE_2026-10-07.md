# WorkBuddy 多轮问答集成验收

日期：2026-10-07。范围：WorkBuddy 重做的“我的助手”多轮问答，与已有 AI 通路改进共同验收。

发布追加：验收后，用户授权合并并生成新版本，本批次纳入 **v2.6.0**。下方保留验收时的版本与验证记录。

## 1. 结论

本次候选完成后端编排、模型路由、数据库历史、前端交互和启动器能力检查的集成。独立审查发现的问题已修复，常规回归、固定评测、生产构建和隔离浏览器检查通过。

验证使用虚构资料和确定性模型替身，覆盖应用流程，不证明真实模型的语义质量、响应速度或费用达标。当前公开版本仍为 v2.5；本批次属于 Unreleased，不新增标签。

## 2. 发现与修复

| 问题 | 修复 | 验证 |
|---|---|---|
| 候选放在 `done.qa`，页面只读顶层 | SSE 与历史详情共享候选解析函数 | 前端行为测试、浏览器点击 |
| 点击只发书名，原问题丢失 | 用候选补充原问题并继续同一会话 | 检查实际 POST 内容和会话编号 |
| 集合比较只提供单个书名 | 提供两个历史讨论对象组成的候选 | API 及浏览器恢复后继续 |
| 澄清未保存，重载不能继续 | 复用 ChatLog 保存本地澄清，详情恢复原问题与候选 | API、数据库和浏览器重载 |
| 澄清依赖模型配置和供应商路由 | 对象判定后直接进入本地通道 | 禁止配置读取的集成测试 |
| 英文 `it` 子串误判 capital / traditional；中文“其他”被判指代 | 英文词边界与受限中文指代规则 | 新增负例与固定集 |
| 短独立问题被当作追问 | 根据显式内容判定，不按长度强制继承主题 | 短概念、英文新问题回归 |
| 第二次追问用泛化句当主题 | 跳过功能词及没有主题的历史问题 | 连续追问检索回归 |
| 指定书目的总结被当作会话总结 | 区分显式资料/概念与会话总结 | 摘要负例 |
| 拼接资料后截断，后续编号没有原文 | 复用共享来源预算构造器 | 8 条超长来源均保留编号及命中原文 |
| 旧 `[资料N]` 引用可能误指新资料 | 移除历史答案的数字引用，本轮重新编号 | 历史提示回归 |
| 多主题会话总结只有最后主题来源 | 重读历史引用的当前原文，限制当前范围与已解析资料 | 双书摘要及越界/删除块过滤 |
| 合并时丢失通用模型覆盖或真实回退记录 | 保留 `model` 覆盖、禁用静默回退、保存实际路由 | 原有审计用例与 API 集成 |
| 读事务跨模型网络等待 | 复制原文字符串后释放读事务 | 流式调用时检查 Session 状态 |
| 把词面重合写成引用支撑、语义已测 | `semantic_status=not_checked`，界面显示词面筛查与人工复核 | 否定句高重合反例、前端文案行为测试 |
| 澄清耗时硬编码 0 且未采集；生成错误遗漏统计 | 真实采集本地耗时，分离本地/模型样本，失败计数 | 指标及错误流集成测试 |
| 弃答精确率与来源非空率混淆 | 无标注精确率为空，代理指标解释边界写入文档 | 指标定义复核 |
| 错误文本覆盖已生成部分 | 保留部分正文并标为未完成；无成功历史入库 | 连接中断后继续提问 |
| 长会话输入区被消息挤出卡片 | 卡片正文 flex 约束、消息独立滚动、输入区固定 | 浏览器几何断言与截图 |
| 窄屏历史过长、候选按钮与模型标签拥挤 | 历史限高滚动、候选换行、模型名称独立展示 | 430 × 932 窄屏检查 |
| 生成期间新会话/历史选择污染会话 | 禁止生成时更换会话或选择候选 | 前端交互检查 |
| 启动器复用旧服务 | API revision 15，检查 `qa_multiturn` 与原文审计能力 | 健康接口与启动器回归 |

## 3. 验证记录

| 检查 | 结果 |
|---|---|
| 常规后端回归 | **534 通过，1 单列**，48.63 秒；单列为真实 PowerPoint 集成 |
| 真实 PowerPoint 集成 | 前一轮完整测试中通过，覆盖原生预览及 PDF 导出；另有 2 个旧问题输入导致的路由用例失败，已修正为明确问题并通过完整回归 |
| 前端单元测试 | **95 通过** |
| 当前生产构建 | **通过**，最终构建 8.40 秒 |
| 多轮固定集 | **28 案门禁通过**；13 案目标文档 Top-1 命中均通过，意图命中 28/28 |
| 原有固定检索集 | **114 案门禁通过**：102 个可回答、12 个拒答；Recall@1 0.9706，Recall@5 0.9902，MRR 0.9853 |
| 浏览器连续流程 | 当前生产构建、真实 API/数据库/FTS，10 次请求覆盖提问、追问、切换主题、澄清继续、摘要、历史恢复、失败恢复和项目隔离 |
| 页面布局 | 1440 × 1000 和 430 × 932；无页面脚本异常、无横向溢出；长会话输入区在卡片内 |
| 数据隔离 | 使用独立工作树和 `.workbuddy` 演示数据；未使用真实资料或调用付费模型 |

两个模型路由旧测试使用“这是什么？”作为输入，现规则会合理走澄清。修正测试输入为明确概念问题，保留所选模型、禁止回退、实际模型与供应商保存的全部断言。

上述固定集为合成材料，本地小型 FTS/重排评测不能替代真实书目与模型评测。浏览器模型替身仅用于验证应用流程与异常处理。
