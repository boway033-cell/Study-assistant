# 功能收敛与布局调整（2026-09-26）

## 功能归属

| 用户任务 | 统一入口 | 保留的能力 | 收敛处理 |
| --- | --- | --- | --- |
| 导入、检索与阅读资料 | 资料库 | 文献、书架、阅读器与原文标注 | 保持一个主入口 |
| 理解单篇或比较文献 | 研读 → 理解与发现 | 论证重建、跨文献发现 | 原独立导航并入研读，旧地址重定向 |
| 向资料提问 | 研读 → 问资料 | 带来源的问答与历史 | 原独立导航并入研读，旧地址重定向 |
| 整理知识 | 研读 → 笔记与证据；知识结构菜单 | 笔记、证据卡、知识树、图谱 | 树与图谱降为次级菜单，旧地址保留 |
| 跨文献成文 | 研读 → 研究报告 | 比较、批判审查、来源与主张审计 | 移除写作页重复的“新建多文献综述”表单 |
| 编辑并交付文章 | 写作 → 作品库 | 独立新作、研究报告、历史综述、去 AI 味结果、Word | 报告可一键转入作品库，重复点击复用同一稿件 |
| 写作风格与表达处理 | 写作 → 写作工具 | Writing DNA、逐条审阅去 AI 味 | 从主标签移到次级工具；新建作品成为默认视图 |
| 公文写作 | 写作 → 公文写作 | 提纲确认、版式与版本 | 与研究写作保持区分 |
| 生成汇报 | 汇报 | 提纲、证据、PPTX | 保留独立任务入口 |
| 系统维护 | 更多工具；设置 | 自测、健康、洞察、模型与数据 | AI 绘图从导航隐藏，旧地址和作品数据保留 |

## 流程与兼容性

研究报告负责生成和审计；作品库负责编辑、去 AI 味和 Word 导出。转入作品库时生成来源指纹，后续打开可以识别报告变更或删除。重复点击“继续写作”返回同一作品，人工修改不会被覆盖。旧版多文献综述保留在作品库，旧接口和旧地址保留兼容，不再在新建流程中出现第二套相似参数。

设置页拆为模型连接、用量与预算、本机与界面三组。模型检测改为用户主动点击，首次进入不再自动发起网络探测。首页去掉缺少 API Key 时的阻断弹窗，避免妨碍本地阅读和演示资料体验。

## 后续观察

观察研究报告转写作作品的使用量、模型连接失败率、作品库打开与 Word 下载完成率。如果研究报告中的“叙事综述”需求显著高于现有体裁能力，再在同一研究入口增加结构预设；不恢复并列生成表单。
