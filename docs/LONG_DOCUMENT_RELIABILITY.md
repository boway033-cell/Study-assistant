## 修复内容

- 目录：保留原始点线、标点和印刷页码的负证据，排除总目录、分篇目录和续页；不再全局保留同名章节的第一次出现。禁止为邻页大字猜配缺失编号。
- 扫描结构：旧版将 OCR 整页文本存成一块，版面分类仅因它从页面顶部开始就判为页眉。现在页眉必须位于页顶区域内部；导入与重建复用页级坐标缓存，恢复行、字号及位置。
- OCR：按路径、大小和纳秒时间戳缓存文件哈希；阅读文字层复用模型；兼容新版 RapidOCR 的数组返回值，保留文本、坐标和置信度。
- 高亮：按文本节点裁剪选择起止位置，避免父元素矩形污染部分选区。双页左右页均可加载 OCR 文字层。
- 双页：有溢出时先滚动，抵达边缘后以新的滚轮手势翻页；惯性事件和连续翻页节流。向上一组翻页落到页底。
- 研究：深度模式读取所选全文（选择父章包含子节）；大于 24000 字时按不超过 12000 字的批次阅读、分层压缩证据后成文。处理覆盖以原始字符数记录。长稿分段生成并持久化草稿，审计单独执行，审计失败仍保存正文。
- 模型等待：每两秒检查进度/取消，单次无内容 120 秒超时、总调用 900 秒超时；已经生成的分段正文中断后保留在任务结果，可回到研究页复制。

## 使用与边界

重启后端并刷新页面后使用新代码。旧目录在“校正目录”内执行重新识别才更新；重建流程记录目录修订，避免静默覆盖人工结果。没有缓存坐标的页面保留正文，不推测字号。

分批读全文增加模型调用次数；界面在深度模式中显示耗时与用量提示。覆盖字符数表示已传入分批阅读，不保证 OCR 无误、模型理解充分或最终文章逐项涵盖全文。尚未进行真实付费模型的整本书成文验收。

## 本轮续作：只补齐未完成链路

### 已写入并通过自动化验收

- **阅读器深度分析入口**：接入已有 `build_chapter_inputs` 与分批精读实现。原入口把根章节的 1-based 序号当作 `Chapter.order_index`，导致错配和空正文；现在按章节 ID/父子关系聚合后代，每个来源块归属一个根章。同名标题通过章节 ID 区分。
- **目录一致性**：精读使用库内现有目录，不再优先从文本块首行重提目录或让 AI 静默补改。没有目录时以全文为一节，不因无目录跳过正文。
- **增量结果**：每完成一章提交总结、Markdown、已完成章节哈希；哈希版本升级，旧的截断/错配总结不会误命中缓存。阅读卡独立生成，失败只提示警告，不丢弃已保存正文；取消仍传播给任务系统。
- **多模型配置**：入口检查标准 `configured` 标记，支持无需 Key 的已配置本地提供方，不只判断旧 DeepSeek Key。
- **阅读页可见进度**：订阅后台任务，约每 5 秒刷新已保存产物，提供取消入口。任务 ID 按书籍保存在浏览器，返回页面可重新订阅；离开或切书终止订阅，旧响应不覆盖新书。
- **研究范围**：失效或不属于当前文献的章节选择报错，不静默扩大阅读范围。研究页六阶段进度条匹配六列宽屏布局。
- **目录 UI 回归夹具**：为 360 页合成 PDF 增加明确原生书签；“校正目录 → 从已解析数据重识别”后的原位更新已经通过浏览器回归。
