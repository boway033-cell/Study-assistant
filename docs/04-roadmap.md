# 04 · 开发路线图

- 版本：v0.4（DeepSeek 云端化 + 知识树；卡片学习已取消）
- 配套：全部 docs 文档

## 0. 总原则

- 每阶段结束都有可演示的成果，先纵向打通、再横向铺开
- 先做「导入 → 解析 → 搜索 → 问答 → 知识树」的最小闭环，再叠加刷题与统计
- **低内存优先**：P0 检索只用 FTS5（零模型内存）；嵌入模型按需启用
- **本地分析优先**：文本解析/切块/检索全部本地；仅 AI 生成（问答/题目/章节兜底）走 DeepSeek 云端
- 每阶段末尾提交一次 git commit
- 开发环境：Python 3.14；所有操作仅在 `study-assistant/` 目录内，不触碰系统原有文件

## 风险清单（含缓解）

| 风险 | 影响 | 缓解 | 触发预案 |
|---|---|---|---|
| 教材无目录/目录乱 | 章节树不准 | 启发式分级 + 手动编辑章节 | 预留编辑接口 |
| 扫描版 PDF | 无法检索 | 检测文本量提示 OCR | OCR 排 P1，不阻塞主线 |
| 云端 Key 失效/欠费 | 问答不可用 | 首次引导 + 设置页探测 + 清晰报错 | 提示充值/换 Key |
| pro 模型响应慢 | 体验差 | flash/pro 可切换 | 日常用 flash |
| 向量化慢 | 导入体验差 | 后台任务 + 进度条；默认关闭 | 模型换 bge-small-zh 量化版 |
| 知识树误删 | 数据丢失 | 删除确认 + 子树级联提示 | 备份 data/ |
| 单机性能瓶颈 | 大书卡顿 | 分页读取、chunk 上限 | 按需索引优化 |
