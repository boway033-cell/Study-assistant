# 产品文档 · Study assistant（学习助手）

> 一份本地部署的个人学习辅助软件，把教材/讲义转化为「AI 问答 + 知识树 + 自测刷题 + 深度分析」的完整学习闭环。
> 本文档包含产品功能介绍与核心特点，并附视觉规范，可直接交予千问（Qwen）生成产品配图。

---

## 一、产品定位

- **名称**：Study assistant（学习助手）
- **一句话**：你的私人 AI 学习助理——上传教材，即可提问、建知识树、刷题、深度精读。
- **目标用户**：需要高效复习大量专业课资料的学生 / 自学者
- **形态**：本地部署的 Web 应用（单机运行，数据不出本机）

### 2.2 风格关键词

**古籍风、学术沉静、手作质感、低饱和怀旧、东方文人美学**。
画面应体现：纸色卡片浮于深青绿背景之上，边缘有细腻描边与柔和阴影，点缀暖赭石色，整体沉稳典雅。

### 2.3 卡片与交互规范

- 所有 Element Plus 卡片及任务、来源、批注、设置等自定义卡片统一使用 `1px #E5E7EB` 边框和 shadow-sm。
- 卡片默认阴影保持克制，普通卡片悬停仅提升至柔和中浅阴影，不做明显漂浮或高对比描边。
- 所有可用按钮悬停时上移 `1px`，按下时回落并缩放至 `0.97`；禁用按钮不得位移。
- 动画只作用于位移、阴影、边框、背景与文字颜色，避免 `transition: all` 引起不必要的重排。
- 遵循系统 `prefers-reduced-motion`：用户选择减少动态效果时取消按钮位移动画。

### 2.4 产品图标建议

一枚书籍 + 知识树/脑图融合的图标，棕褐 + 米白配色，圆角，简洁线条，避免高饱和。

## 三、功能介绍

### 3.1 资料管理
- 上传 PDF / Word / PPT 教材，自动解析、提取章节、版面分析、文本清洗
- 中文全文搜索（关键词命中片段 + 页码 + 章节）
- **AI 自动分类**：自动识别文献学科归类，资料库分组展示
- 智能分析：自动提取定义、定理、关键词
- 用户可建立多级书架，批量把资料归入单个或多个书架；书架只管理知识库关系，不改动磁盘原文件
- “我的资料”采用阅读导向条目：题名与来源优先展示，阅读进度、解析状态、分类和深度分析分组呈现；阅读中的资料直接显示“继续阅读”
- 支持当前书架内检索、多条件筛选、收藏过滤、一键清除筛选、全选结果与批量归档；批量导入先确认文件队列，再进入全局任务中心

### 3.2 AI 问答
- 对整本教材提问，AI 基于原文回答并标注出处页码
- 答案右侧实时展示引用原文（文本 / PDF）
- 支持 fast（快速）/ pro（深度推理）两档模型切换
- 跨书综合提问（AI 自主选取多本相关文献）

### 3.3 知识树
- 大纲树 + 思维导图双视图，一键切换
- 手动搭建 / 从章节一键导入 / AI 自动生成框架
- 节点：类型标记（概念/定理/考点/例题/疑问）、掌握度（已掌握/模糊/未掌握）、笔记（Markdown）
- 节点关联教材章节，右侧看原文；跨树节点引用；AI 批改笔记
- 导图可导出图片，按掌握度着色，一目了然薄弱点

### 3.4 深度分析（标题目录 + 精读 + Markdown）
- 自动提取三级标题目录（章/节/小节），核对缺失并 AI 补全
- 按整本文献的编号状态链检查缺号、重号、倒序、父子层级和同页阅读顺序，置信度会因逻辑冲突下调
- 有唯一证据时自动回挂错位子项；缺失标题、疑似正文和多解问题不自动臆造
- 三栏目录工作台同时展示虚拟折叠树、对应原页和节点检查器；可撤销、整组移动、升降级、新增删除并逐项处理异常
- AI 按目录逐章精读总结
- 整本书转化为 Markdown 精读版，阅读器内一键切换查看

### 3.5 AI 研读
- **综合阅读报告**：AI 通读文献，输出主题脉络、文献定位、交叉知识点、学习路径
- **思维训练**：苏格拉底式出题 + 批改 + 追问，或自由陪练，多轮训练直到吃透

### 3.6 PDF / Word / PPT 阅读器
- PDF：连续/单页/双页三种阅读模式，缩放稳定后重绘，只保留可见页控制内存；支持四色高亮、批注、深色、目录和位置记忆
- Word/PPT：默认使用本机 Office 按需生成高保真原版页面，同时保留可检索、可选中的结构文本视图；Office 完成后立即退出
- 选中文字 → AI 解释 / 翻译 / 询问 / 高亮
- PDF 页面 → AI 视觉解读（图表/公式/示意图）

### 3.7 刷题自测与统计
- AI 分析教材内容自动生成题目（选择/填空/简答），自动判分
- 错题本、薄弱章节排行、掌握度可视化

### 3.8 文献汇报工作台

- 从整篇、指定章节、阅读器选段或补充材料中明确选取证据边界。
- 长文献按章节分层取样，不会只截取文首；界面展示内容覆盖率、结构覆盖率和分组覆盖。
- 生成 PPTX 前必先预览可编辑提纲，可调整页序、删增页面、修改主张/要点与来源。
- 主张—来源审计检查数字、关键词、页码/章节定位与 source ID，把“部分支持/需复核/不支持”显示给用户。
- SI、图表、数据集统一记录许可证、权利状态、归属文字与来源路径；公开/商业汇报默认排除权利不明图像。
- 本机安装 PowerPoint 时真实渲染逐页 PNG 供审阅，并生成与上一版的视觉差异报告。
- 文献页面导入会先发现页面中的 PDF 候选；公开文件直接校验导入，依赖馆藏登录的入口交给当前 Chrome，应用不读取浏览器 Cookie。
- 默认文本分析仍使用 DeepSeek；可登记并检测其他 OpenAI Chat Completions 兼容的文本/多模态接口，但不会静默替换默认厂家。

## 四、核心特点（卖点）

1. **本地优先，隐私安全**：原始文件不出本机；仅启用 AI 时，问答/深度分析/出题/研读/知识树/视觉分析会把相关片段或图像发给 DeepSeek / Qwen-VL（详见 README）
2. **低内存设计**：检索默认零模型（纯 FTS5），向量/OCR 按需启用
3. **双模型驱动**：DeepSeek（问答/总结/训练）+ Qwen-VL（视觉理解）
4. **从「读」到「懂」**：不只是问答，更有知识树结构化、思维训练、掌握度追踪
5. **古籍学术风 UI**：沉静典雅，随节气变化，学习有仪式感
6. **一键部署**：双击即启动，数据本地 SQLite，备份 = 复制一个目录

---

## 五、技术亮点

- 前端：Vue3 + Vite + Element Plus + pdf.js（免下载内嵌阅读）+ ECharts
- 后端：Python 3.14 + FastAPI + SQLAlchemy + SQLite(WAL) + FTS5 全文检索
- RAG：语义切块 + FTS5 + 可选向量检索（fastembed + ChromaDB），四层降级绝不答非所问
- AI：DeepSeek（flash/pro 双档）+ Qwen-VL（视觉），后台任务异步执行，失败自动重试
- 深度分析管线：三级标题提取 → 核对 → AI 补全 → 逐章精读 → Markdown
