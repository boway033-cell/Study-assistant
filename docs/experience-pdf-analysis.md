# 可复用经验：教材 PDF 深度分析方法论

> 来源：以真实教材《公共管理学》（456 页，无书签）为实战样本，迭代验证沉淀。
> 适用于任何文字版教材 PDF/Word 的智能分析、章节提取、向量检索、知识结构化。

---

## 一、处理流水线总览

```
上传 → 解析(PyMuPDF) → 扫描件检测(页均<30字符→OCR)
     → 版面分析(字体/字号/坐标) → 文本清洗(页眉页脚/去重/断行)
     → 章节提取(书签 → 启发式 → LLM) → 语义切块(段落边界+页码映射)
     → FTS5 索引(jieba) → 向量化(fastembed,可选) → 关键信息/知识树素材
```

> 以上分析**全部在本地完成**；只有「章节提取的 LLM 兜底」可选走 DeepSeek 云端。

## 二、关键经验（按踩坑顺序）

### 1. 章节提取：书签 → 启发式 → LLM 三级兜底

**教训**：真实教材常无书签（《公共管理学》0 个书签），不能只依赖 PyMuPDF `get_toc()`。

| 级别 | 方法 | 适用 | 效果 |
|---|---|---|---|
| 1 | PDF 书签 | 有书签的书 | 100% 准确 |
| 2 | **启发式扫描「第X章」模式** | 无书签但有编号标题 | 17/18 章（本案例） |
| 3 | LLM 提取 | 无编号/特殊排版 | 需配置模型（DeepSeek） |

**启发式正则要兼容的排版变体**（都遇到过）：

```
第1章公共管理导论 3            # 紧凑 + 尾随页码
第 3 章 | 公共管理的价值        # 空格 + 竖线分隔
第 4 章 公 共 管 理 的 环 境    # 字距空格
第7章 | 公共政策的设计、执行与评估
```

关键点：正则允许空格和 `|` 分隔符；标题字符集放宽；`_clean_title` 去掉字距空格、页码尾巴、正文开头噪声（"随着/自从/在"等）。

**目录页过滤**：目录项常带点线（`......`），正则检测 `[.．·]{4,}` 跳过。

**页眉重复去重**：章节标题会在每页页眉重复出现 → 按「第X章」编号去重，只保留首次。

### 2. 文本清洗顺序陷阱

**教训**：`merge_broken_chinese`（断行合并）会**把标题行和正文黏连**，污染章节提取。

修复：合并前检查**上一行**是否像标题（`_looks_like_title`），标题行保持独立；行尾是数字（页码）视为闭合。

### 3. 语义切块：段落边界优先于字符窗口

- 按空行/句末标点切自然段 → 合并成语义块（500-900 字符）
- **每块保留页码映射**（page_start/page_end）——这是「原文定位面板/知识树原文」的数据基础
- 长段落按句末标点二次切分

### 4. 向量检索：低内存 + 国内网络

- **fastembed**（ONNX，~100MB）替代 sentence-transformers（torch，1.5GB+）
- **模型下载**：HuggingFace 被墙 → 用**多线程分块下载** GCS URL
  （`https://storage.googleapis.com/qdrant-fastembed/fast-bge-small-zh-v1.5.tar.gz`，8 线程 Range 下载）
- 解压到 `cache_dir/fast-bge-small-zh-v1.5/`，设 `HF_HUB_OFFLINE=1` 全离线加载
- **混合检索**：向量语义召回 + FTS 关键词 + LIKE 兜底，去重合并
- 验证：问"数字政府的含义"→ 命中第14章数字政府（语义理解，非关键词）
- **默认关闭**：`vector_search=false`（省内存），按需开启

### 5. 后台任务：FastAPI sync 端点线程池陷阱

**教训**：sync 端点（`def`）在 AnyIO 线程池运行，`asyncio.get_event_loop()` 会失败（无事件循环）。

修复：**独立后台线程 + 独立事件循环**：
- 线程内 `loop.run_forever()`，`threading.Event` 等待就绪
- `submit` 用 `run_coroutine_threadsafe` 提交，worker 里 `await asyncio.wrap_future(future)`
- 队列 put 不阻塞等待（避免竞态超时）

### 6. 知识树原文关联（替代原卡片生成）

- 知识树节点可关联书籍章节：`GET /api/knowledge/nodes/{id}/source` 合并该章全部 chunk 文本
- 合并文本保留 page_start/page_end，配合 PDF iframe（`#page=N`）可精确回看原文
- 建议：节点标题用「概念/主题」而非教材章节号，便于跨书整合

### 7. 数据一致性

- 删除/重导书籍要级联清理：BookAnalysis、向量库（ChromaDB）、FTS 索引——否则外键失败
- 知识树删除节点要级联删除子树

## 三、性能参考（《公共管理学》456 页实测）

| 环节 | 耗时 |
|---|---|
| 解析 + 版面分析 + 清洗 | ~10s |
| 语义切块（797 块） | <1s |
| FTS 索引 | ~2s |
| 向量化（fastembed CPU） | ~60s（一次性，默认关闭） |
| 智能分析（定义/关键词） | <1s |

## 四、复用到新教材的检查清单

1. 上传后确认 `chapters` 数量合理（非 1）——否则检查启发式正则是否匹配该书排版
2. 抽查 3 个章节标题是否混入正文——是则扩展 `_clean_title` 噪声词
3. 搜索一个冷门概念验证 FTS 命中
4. 向量检索开启后验证语义问题命中
5. 用知识树关联核心章节，验证右侧原文可回看
