- 版本：v0.2（已按「低内存占用 / FTS5 检索优先 / 不触碰系统原有内容」修正）

## 1. 背景与问题

### 1.1 背景

用户为保研学生，需在有限时间内复习多门专业核心课。学习资料形态多样：

- 教材 PDF（数百页，含扫描版）
- 讲义 / 课件 Word、PPT
- 往年真题、自己的笔记

### 1.2 核心痛点

| 痛点 | 说明 |
|---|---|
| 内容量大 | 每门课是一整本书，逐页精读不现实 |
| 检索困难 | 想找某个知识点，不知道在哪本书哪一章 |
| 记忆易忘 | 概念、定理、公式背了忘，缺少科学的复习排期 |
| 缺乏自测 | 不知道掌握程度，考前才发现漏洞 |
| 面试无准备 | 保研面试爱问跨章节联系、专业热点，无系统积累 |

### 1.3 目标

> **第一性目标**：把「读资料」变成「主动回忆 + 自测 + 查漏补缺」。

具体为：

1. 一本书导入后 1 分钟内可检索、可提问
2. 每天打开软件 10 分钟完成智能排期的卡片复习
3. 每章学完可一键生成练习题自测，掌握度可视化
4. 面试前可基于资料库生成高频问题并演练

## 2. 用户画像

| 项 | 值 |
|---|---|
| 身份 | 保研学生（单人使用） |
| 设备 | Windows 个人电脑，单机 |
| 编程水平 | Python 为主，可改后端代码 |
| 使用频率 | 每日，复习季高强度 |

## 3. 功能需求

优先级定义：**P0**（MVP 必须）、**P1**（第二阶段）、**P2**（打磨/后期）。

### 3.1 资料管理（P0）

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| F1.1 | 上传 PDF / Word(.docx) / PPT(.pptx) 文件 | P0 | 支持拖拽与文件选择，上传后进入解析队列 |
| F1.2 | 自动提取目录与章节结构 | P0 | 生成章节树（多级），无目录的书按页数自动分章 |
| F1.3 | 解析进度可视化 | P0 | 解析中显示进度与当前步骤，失败可重试 |
| F1.4 | 全文搜索（中文） | P0 | 输入关键词返回命中片段 + 页码 + 章节，支持按书/章过滤 |
| F1.5 | 扫描版 PDF OCR（可选） | P1 | 检测到无文本层时提示启用 OCR（PaddleOCR） |
| F1.6 | 阅读器内标注与笔记 | P1 | pdf.js 阅读器内高亮/批注，笔记可检索 |
| F1.7 | 删除/重命名/重新解析 | P0 | 数据级联清理 |
| F1.8 | **录入后智能分析** | P0 | 版面识别（标题/正文/页眉页脚/表格/公式），提取关键定义/定理/关键词，详情页展示 |
| F1.9 | **扫描版 OCR** | P1 | 页均文本过低自动检测，OCR 后端可插拔（tesseract/paddle），自动清洗文本重复与残缺 |

### 3.2 AI 对书提问（P0）

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| F2.1 | 基于资料库的 RAG 问答 | P0 | 提问 → 检索相关片段 → 生成答案，流式输出 |
| F2.2 | 答案标注出处 | P0 | 每条答案附引用片段与页码，可点击跳转 |
| F2.3 | 本地 / 云端双模式切换 | P0 | 设置页一键切换；云端模式可配置 API Key |
| F2.4 | 对话历史 | P1 | 按书保存历史问答，可回看删除 |
| F2.5 | 跨书提问 | P1 | 可选"全部书籍"范围，回答跨书综合问题 |
| F2.6 | **宽定位检索** | P0 | 主检索 + LIKE 降级 + 章节级上下文 + 目录兜底，保证任何概念都能命中并完整输出文献内容 |

### 3.3 卡片背诵（P0）

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| F3.1 | 自动生成问答卡片 | P0 | 选中章节 → 生成「概念定义 / 简答」卡片，可预览后批量导入 |
| F3.2 | 手动建卡 | P0 | 手动创建/编辑/删除卡片 |
| F3.3 | FSRS 间隔重复 | P0 | 复习按 FSRS 排期；评级（忘记/困难/良好/简单）驱动算法 |
| F3.4 | 每日复习队列 | P0 | 首页显示今日到期卡片数，复习流程：看题 → 想答案 → 翻面 → 评级 |
| F3.5 | 卡片标签与按书筛选 | P1 | 支持标签（如"高频""易错"） |

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 部署 | 本地一键启动，浏览器访问；无需联网即可用（本地 AI 模式） |
| 性能 | 500 页 PDF 解析 ≤ 60 秒（不含 OCR）；问答首 token ≤ 3 秒（云端） |
| **内存** | **空闲内存 < 7GB 的机器上流畅运行：后端常驻 ≤ 500MB；P0 检索不加载任何模型（纯 FTS5）；嵌入模型与本地 LLM 均按需启用、用完可卸载，避免常驻大模型** |
| 数据 | SQLite + 文档文件 + 向量库均在本机；提供备份说明 |
| 隐私 | 默认本地模式；云端模式仅上传「提问 + 检索片段」 |
| 兼容 | Chrome / Edge 现代浏览器 |
| 可维护 | 单人开发，代码分层清晰，关键模块可替换（LLM、解析器） |
| 安全 | 全部开发/运行产物仅写入项目目录（study-assistant/），不修改系统原有文件 |

## 5. 非目标（本期不做）

- 多用户 / 账号体系
- 移动端 App
- 多人协作 / 云端同步
- 语音识别（面试录音仅 P2 后期）
- 复杂的富文本编辑器

## 6. 成功指标（自测）

- 导入 5 本核心教材，全部完成解析与索引
- 每天完成当日复习队列 ≥ 90%
- 每门课生成 ≥ 100 张卡片、≥ 50 道自测题
- 面试前能从资料库答出 80% 高频问题
