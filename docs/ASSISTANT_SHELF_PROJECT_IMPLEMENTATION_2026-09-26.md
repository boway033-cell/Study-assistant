# 书架与项目助手：首个可用闭环

## 用户路径

1. 在资料库创建书架并加入资料，点击书架标题旁的“书架助手”。
2. 在“我的助手”选择书架或项目。项目可以动态引用书架，也可以单独引用资料；改变书架成员后，项目范围随之更新。
3. “逐本状态”显示解析、可读正文、全文研读、过期与失败状态。点击“研读范围资料”先查看模型、预计调用次数、Token 和已配置费率下的费用粗估，再确认提交。每批最多八本，每本独立计入现有 AI 任务上限。
4. 助手问答只能检索当前范围内已解析的资料；有当前版本全文研读结果时，还会从论证图定位相关原文片段。答案保留原有的来源标签和原文定位。
5. 用户可以直接保存目标、观点、问题或偏好，也可以在对话中点“记到我的记忆”。这些记录可编辑、删除；助手只使用用户明确保存的内容。若全文论证与个人问题可能有关，侧栏显示可核对的原文入口。
6. 同一范围的追问会保留会话编号；“新对话”可清空当前会话。模型仅看到最近的用户问题以理解“它”等指代，过去的模型回答不进入新一轮事实依据。

## 数据边界

- `Shelf` 与 `Book` 沿用现有多对多关系。`AssistantProject` 通过关联表引用书架与单本书，不复制文件。书架范围只含该书架直接归档的资料，和资料库现有的书架列表语义一致。
- `AssistantMemory` 属于书架或项目。项目问答还可以使用其引用书架的已确认记忆；原有 `KnowledgeNote` 中用户撰写且属于当前资料范围的笔记也可以进入个人上下文。
- `SensemakingArtifact` 的全文论证图沿用原有正文摘要、来源版本和提示词版本。资料或提示词版本变化后，该结果不再进入问答或关联提示。
- 项目/书架检索在解析范围时即限定书籍 ID；空范围返回明确错误。模型提示词将原文、用户记录和 AI 推断分开，个人记录不能当作原文事实。
- 新的全文研读任务走独立的后台 AI 队列，不占用交互式 AI 任务队列。服务重启后任务会标为中断，逐书阅读检查点可在重新提交时继续使用。
- 旧问答记录在启动时增量补充范围和会话列；旧记录继续可读。新会话按书、书架或项目隔离。

## 本阶段边界

“全文研读”覆盖已经成功解析出的文本块，扫描页若没有 OCR 正文仍需先修复解析。关联提示仅表明论证图和个人问题存在文本上的可能关系，用户需要核对原文；它不自动改写个人记忆。问答中的引用编号可校验，但语义支持仍需人工核对。费率由用户填写，费用为粗估，不代替供应商账单。
